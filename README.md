# Connectx
A Connect Four (Kaggle ConnectX) agent combining alpha-beta minimax search with a self-play-trained NNUE    evaluation network. Pure-NumPy inference, 49-bit bitboards, transposition table, killer/history move ordering, and    LMR — engineered for CPU-only, 2-second-per-move constraints. ~1200 on the public leaderboard (top 15%).
